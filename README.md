# Safaa Mamoun — Academic Portfolio

Static files for Safaa Mamoun's academic website.

## Publish with GitHub Pages

1. Create a public GitHub repository named `Safaa997.github.io`.
2. Upload the **contents** of this folder so `index.html` is at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/(root)` folder, then save.

The essay is in `essay/index.html`; the photograph and CV are in `assets/`.
